# 📚 Library Management System (CLI - Java)

A simple and efficient **Command Line Interface (CLI) based Library Management System** built using **Java and Object-Oriented Programming (OOP)** principles. This project allows users to manage books, issue and return books, and maintain library records directly from the terminal.

---

## 🚀 Features

✨ Add new books
📖 View all available books
📤 Issue books
📥 Return books
🗑️ Delete books
🧠 Object-Oriented Design
🖥️ Interactive CLI menu system

---

## 🛠️ Technologies Used

* ☕ Java
* 📦 ArrayList (Collection Framework)
* 🧱 Object-Oriented Programming (OOP)
* 💻 Command Line Interface (CLI)

---

## 📂 Project Structure

```
LibraryManagementSystem/
│
├── Main.java        # Entry point of the application
├── Book.java        # Book class with properties and methods
└── Library.java     # Library management logic
```

---

## ⚙️ How It Works

The system allows users to perform various library operations using a menu-driven interface.

### Menu Options:

```
1. Add Book
2. View Books
3. Issue Book
4. Return Book
5. Delete Book
6. Exit
```

## ▶️ How to Run

### Step 1: Clone the repository

```
git clone https://github.com/your-username/library-management-system.git
```

### Step 2: Navigate to project folder

```
cd library-management-system
```

### Step 3: Compile the program

```
javac Main.java Book.java Library.java
```

### Step 4: Run the program

```
java Main
```
